DunckOps Self-Hosted

Instalador oficial DunckOps

Este dominio distribui os arquivos publicos de instalacao do DunckOps Platform. O codigo-fonte permanece privado; a instalacao usa imagens publicas e uma license key.

curl -fsSL https://get.dunckops.com/install.sh | sudo bash
install.sh docker-compose.prod.yml docker-ops override env.production.example

Requisitos: Docker 24+, Docker Compose v2+ e uma license key ativa.
