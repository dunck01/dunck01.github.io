DunckOps Self-Hosted

Instale sua stack DunckOps em uma VPS

Este dominio distribui o instalador self-hosted oficial. Execute o comando abaixo na VPS e configure a licenca no primeiro login. Se voce nao informar uma chave, uma licenca gratuita sera configurada automaticamente.

Ver planos no site oficial Entrar Minhas licencas
curl -fsSL https://get.dunckops.com/install.sh | sudo bash
1. Rode na VPS O instalador baixa tudo em /opt/dunckops e sobe Postgres, MinIO, API, worker, web e Docker Agent.
2. Entre na conta Use sua conta DunckOps no login da instancia self-hosted.
3. Configure a licenca Informe sua chave ou deixe em branco para ativar o plano gratuito.
install.sh docker-compose.prod.yml docker-ops override env.production.example dunckops.com

Requisitos: Docker 24+, Docker Compose v2+ e uma conta DunckOps. Atualizacao padrao: cd /opt/dunckops && ./scripts/update.sh.
