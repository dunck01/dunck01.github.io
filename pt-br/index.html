DunckOps Self-Hosted

Instale sua stack DunckOps em uma VPS

Este domínio distribui o instalador self-hosted oficial. Execute o comando abaixo na VPS e configure a licença no primeiro login. Se você não informar uma chave, uma licença gratuita será configurada automaticamente.

Ver planos no site oficial Entrar

Defina DUNCKOPS_VERSION com uma release X.Y.Z realmente publicada no catálogo oficial, sem prefixo v. Nunca use latest ou um número fictício.

curl -fsSL https://get.dunckops.com/install.sh | sudo env DUNCKOPS_VERSION="${DUNCKOPS_VERSION:?Selecione uma release publicada}" bash
1. Rode na VPS O instalador baixa tudo em /opt/dunckops e sobe Postgres, MinIO, API, worker, web e Docker Agent.
2. Entre na conta Use sua conta DunckOps no login da instância self-hosted.
3. Configure a licença Informe sua chave ou deixe em branco para ativar o plano gratuito.

Bancos de dados

PostgreSQL continua sendo o motor operacional disponível. MySQL, MariaDB, MongoDB e Microsoft SQL Server estão no roteiro de implementação, ainda sem backup, PITR ou réplica com atraso disponíveis nesta versão.

Todos os planos autorizam os mesmos motores; limites e recursos variam conforme o plano. O limite de bancos conta o total combinado entre motores. Essa autorização não habilita recursos ainda não implementados. O instalador permanece inalterado nesta etapa.

install.sh docker-compose.prod.yml Sobrescrita do Docker Ops env.production.example dunckops.com

Requisitos: Docker 24+, Docker Compose v2+ e uma conta DunckOps. Atualização padrão: cd /opt/dunckops && ./scripts/update.sh.
